# Командный мини-проект

Браузерная игра «поиск пар» на археологическую тематику. 
Вы руководитель экспедиции: нужно вскрыть участки раскопа и найти все пары артефактов, пока не закончился грант (таймер).

## Играть

После публикации добавьте сюда ссылку на GitVerse Pages.

## Управление

Нажатие левой кнопки мыши по карточке по карточке переворачивает её и показывает артефакт.
Откройте вторую карточку:
Если артефакты совпали: пара остаётся открытой с пометкой «найдено»;
Если не совпали: через 1 секунду обе карточки закрываются.
Играть снова: кнопка на итоговом экране, запускает новый раунд без перезагрузки страницы.
